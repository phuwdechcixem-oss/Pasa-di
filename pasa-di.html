ภาษาดีเพราะมีเรา

พิมพ์ข้อความ เลือกระดับภาษา แล้วให้เว็บเปลี่ยนคำให้เหมาะกับคนที่จะอ่าน

ใส่ข้อความ แล้วเปลี่ยนให้

โหมดเอไอ (ไม่บังคับ ใช้ API key ของตัวเอง)

เกลาไวยากรณ์ได้ละเอียดที่สุด ต้องต่ออินเทอร์เน็ตและมี API key ของ Anthropic ซึ่งคิดค่าใช้จ่ายตามการใช้งาน key เก็บในเบราว์เซอร์เครื่องนี้เท่านั้น อย่าใส่ถ้าใช้เครื่องสาธารณะ

ตัวอย่าง

เลือกประโยค ดูว่าคำเปลี่ยนไปยังไงในแต่ละระดับ

ประกอบรายงานการศึกษาค้นคว้าด้วยตนเอง เรื่อง การใช้ภาษาไทยในยุคดิจิทัล รายการคำรวบรวมจากความรู้ทั่วไป ไม่ได้ลอกจากพจนานุกรมโดยตรง ก่อนใช้จริงควรตรวจเทียบกับพจนานุกรมฉบับราชบัณฑิตยสภา
